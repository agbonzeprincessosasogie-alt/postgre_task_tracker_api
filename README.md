# Task Tracker API

A RESTful Task Tracker API built with Node.js, Express, PostgreSQL, and TypeORM.

## Features

- User registration
- User login
- Password hashing with bcrypt
- JWT authentication
- Create tasks
- Get all tasks
- Get a task by ID
- Update tasks
- Delete tasks
- User-task relationship using TypeORM
- Task ownership authorization
- MVC architecture
- Service layer
- PostgreSQL database

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- TypeORM
- JWT
- bcryptjs
- Postman
- Git & GitHub
